# LAIA - Asistentes de prueba

Prototipos de asistentes académicos para la Universidad Autónoma de Occidente (UAO).

## Objetivo

Desarrollar y validar localmente dos asistentes de inteligencia artificial:

- Asistente Docente
- Asistente Estudiante

Los asistentes utilizan Ollama como proveedor local de modelos de lenguaje.

## Estado

Prototipo inicial en desarrollo.

## Arquitectura

- Python para la lógica de aplicación.
- Ollama para la inferencia local.
- Instrucciones independientes por asistente.
- Ejecución mediante consola.
- Pruebas funcionales y de comportamiento.

## Integración futura

La adaptación a LucIA está pendiente de validar sus especificaciones técnicas, mecanismos de creación de asistentes y formatos admitidos.
