## Actividad de Aprendizaje: Variables en Python - 15 Minutos

**Objetivo:** Comprender el concepto de variables en Python y cómo usarlas para almacenar y manipular datos.

**Duración Total:** 15 minutos

**Materiales:**

*   Ordenador con Python instalado (o acceso a un entorno de desarrollo como Google Colab)
*   Ejemplo de código Python (opcional, para facilitar la comprensión)

**Etapas:**

1.  **Introducción (2 minutos):**
    *   **Descripción:**  Explicar brevemente qué es una variable en programación.  Usar analogía con una caja donde se guarda información.
    *   **Pregunta:** "¿Qué es una variable?  ¿Por qué es importante?" (Pregunta abierta para fomentar la participación).
2.  **Ejemplo de Código (5 minutos):**
    *   **Descripción:**  Mostrar un ejemplo sencillo de cómo crear una variable y asignarle un valor.
    *   **Código:**
        ```python
        nombre = "Juan"
        edad = 20
        print("Hola, mi nombre es", nombre)
        print("Tengo", edad, "años.")
        ```
    *   **Instrucciones:**  "Observen cómo asignamos valores a la variable 'nombre' y 'edad'.  ¿Qué es lo que sucede cuando asignamos un valor a una variable?"
3.  **Práctica (4 minutos):**
    *   **Descripción:**  Pedir a los estudiantes que creen sus propias variables y asignen valores.
    *   **Instrucciones:** "Ahora, cree tres variables: 'mi_nombre', 'mi_edad' y 'mi_altura'.  Asigne valores a cada una.  Luego, imprima cada una de estas variables."
4.  **Conclusión (2 minutos):**
    *   **Descripción:**  Resumir brevemente el concepto de variables.
    *   **Pregunta:** "¿Qué es lo que sucede cuando se usa una variable en Python?" (Pregunta rápida para asegurar comprensión).

*   Verificar que los estudiantes hayan creado y asignado valores a las variables.

**Notas:**

*   Adaptar el ejemplo de código a las necesidades específicas de los estudiantes.
*   Enfatizar la importancia de la nomenclatura (usar nombres descriptivos para las variables).

This activity is designed to be quick and engaging, providing a foundational understanding of variables in Python.  It prioritizes active learning through practical application and immediate feedback.

¡Hola! Vamos a hablar de variables en Python.

**¿Qué es una variable?**

En Python, una variable es como una caja o un contenedor que almacena un valor. Puedes pensar en ella como una etiqueta que le das a un dato específico.  Esta etiqueta puede contener números, texto, o incluso otros valores.  La clave es que puedes cambiar el valor que contiene la variable a lo largo de tu programa.

**Ejemplo sencillo:**

Imagina que quieres guardar el nombre de una persona en tu programa.  Podrías crear una variable llamada `nombre` y darle al valor "Juan".  Ahora, cuando quieras mostrar el nombre de la persona, simplemente puedes usar el valor de la variable `nombre`.

```python
nombre = "Juan"
print(nombre)  # Imprime: Juan
```

En este ejemplo, `nombre` es una variable.  Almacena el valor "Juan".  La variable `nombre` es una etiqueta que le damos a ese valor.

**Ahora, una pregunta para que ver si entiendes:**

Imagina que quieres calcular el área de un círculo.  ¿Qué tipo de variable necesitarías para almacenar el radio del círculo?
