## Actividad de Aprendizaje: Variables en Python - 15 Minutos

**Objetivo de Aprendizaje:** Los estudiantes comprenderán qué son las variables, cómo declararlas en Python y cómo usar variables para almacenar y manipular datos.

**Duración Total:** 15 minutos

**Materiales:**

*   Ordenador/Tableta con Python instalado (o acceso a un entorno de desarrollo como Google Colab)
*   Ejemplo de código Python (opcional, para facilitar la comprensión)

**Etapas:**

1.  **Introducción (2 minutos):**
    *   Breve explicación de lo que son las variables: "Las variables son como cajas o contenedores que almacenan datos.  En Python, las variables son nombres que le damos a los valores que queremos guardar."
    *   Ejemplo: "Imagina que tienes una variable llamada 'edad' que guarda el número de años de alguien."

2.  **Declaración de Variables (5 minutos):**
    *   Mostrar el código:  `edad = 25`
    *   Explicar: "En Python, para declarar una variable, se usa el nombre de la variable seguido de un signo igual (=).  El valor que le asignamos es el dato que guardamos."
    *   Practicar:  "Ahora, vamos a declarar una variable llamada 'nombre' y darle el valor 'Juan'."

3.  **Operaciones con Variables (5 minutos):**
    *   Mostrar el código: `nombre = "Juan"`
    *   Explicar: "Ahora, podemos usar variables para realizar operaciones con datos.  Por ejemplo, podemos sumarle 5 a 'nombre' y mostrar el resultado."
    *   Practicar: "Vamos a sumarle 5 a 'nombre' y mostrar el resultado." (Mostrar el resultado en la pantalla)

4.  **Ejemplo Práctico (3 minutos):**
    *   Mostrar un ejemplo simple:  `x = 10`
    *   Explicar: "Ahora, vamos a crear una variable llamada 'multiplicacion' y darle el valor 5.  Luego, podemos usar 'multiplicacion' para calcular el resultado de 5 * 2."
    *   Practicar: "Calcula 5 * 2."

5.  **Resumen y Pregunta (1 minuto):**
    *   Resumir: "En resumen, las variables son nombres que almacenan datos, y podemos usar variables para realizar operaciones con ellos."
    *   Pregunta: "¿Qué es una variable en Python?"

**Evaluación:** Observar la participación de los estudiantes durante las actividades y la comprensión de los conceptos clave.
